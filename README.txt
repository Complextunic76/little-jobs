LITTLE JOBS — ANDROID PWA

This package contains the complete 52-job app. No accounts, analytics, reminders, or notifications.

FREE HOSTING VIA GITHUB PAGES
1. Create a free GitHub account (if you don't have one).
2. Create a PUBLIC repository, e.g. little-jobs. (Public means the app's source and default job names are visible to others; your completion history stays on your device.)
3. Extract this ZIP. Upload the FILES INSIDE the household-job-bank folder to the ROOT of your repository (index.html, app.js, data.js, style.css, sw.js, manifest.webmanifest and icons). Do not upload the enclosing folder alone.
4. In the repository go to Settings > Pages > Build and deployment. Choose Deploy from a branch, branch main, folder / (root), then Save.
5. Once published, open https://YOUR-USERNAME.github.io/little-jobs/ in Chrome on Android.
6. Tap Chrome's three-dot menu > Install app (or Add to Home screen).

BACKUPS
Settings > Download backup. Save the JSON somewhere safe (e.g. Google Drive). Restore from backup to move your job bank to another phone. Data does NOT automatically sync across devices.

IMPORTANT
GitHub Pages can take a few minutes to publish. The PWA must be opened via HTTPS to install and cache for offline use. Do not open index.html directly from a file manager and expect installation/offline support. The app stores progress locally in browser storage; clearing site data can erase it.
